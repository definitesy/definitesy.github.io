总结：核心流程一览

步骤 核心命令
安装 Hexo npm install -g hexo-cli
创建项目 hexo init my-blog && cd my-blog && npm install
写文章 hexo new "标题" → 编辑 source/_posts/标题.md
本地预览 hexo server → 浏览器访问 http://localhost:4000
生成静态文件 hexo clean && hexo generate → 输出到 public/
部署上线 Nginx 托管 public/ 目录，或用 hexo deploy 自动部署

核心原理：Hexo 是基于 Node.js 的静态博客框架。它将 Markdown 文章 + 主题模板渲染为完整的 HTML/CSS/JS 静态网站。生成的 public/ 目录就是网站全部内容，可直接部署到 Nginx、Apache、Caddy 等任意 Web 服务器，无需 Node.js 运行时。
